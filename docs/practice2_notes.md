# Пояснительная записка к практической работе 2

## Что добавлено

Во второй практической работе проект **SmartBasket** расширен двумя новыми экранами:

1. **Экран "Покупки"** - экран просмотра плана покупок на день.
2. **Экран "Настройки"** - экран будущих настроек приложения.

На стартовом экране добавлены две иконко-кнопки для будущих переходов: "Покупки" и "Настройки".

## Соответствие стилю первого экрана

Новые экраны используют ту же визуальную систему, что и первый экран:

- основной зеленый цвет `#2E7D32`;
- темно-зеленый цвет для заголовков `#1B5E20`;
- светло-зеленые панели и фоны;
- желто-оранжевый акцент `#FFB300` для основных действий;
- скругленные карточки, поля и кнопки.

## Иконки и изображения на экранах

На каждом экране присутствует не менее двух компонентов с изображениями/иконками:

### Главный экран

- `ImageView` с иконкой корзины приложения.
- `ImageButton` перехода на экран "Покупки".
- `ImageButton` перехода на экран "Настройки".

### Экран "Покупки"

- `ImageButton` возврата на главный экран.
- `ImageButton` перехода в настройки.
- `ImageView` с иконкой списка покупок.

### Экран "Настройки"

- `ImageButton` возврата на главный экран.
- `ImageButton` перехода на экран "Покупки".
- `ImageView` с иконкой настроек.

## XML-слушатели нажатий

Для кнопок и иконко-кнопок добавлены XML-слушатели через атрибут `android:onClick`.

### Главный экран `main_activity.xml`

- `openShoppingScreen` - переход на экран "Покупки".
- `openSettingsScreen` - переход на экран "Настройки".
- `addProduct` - будущая логика добавления товара.
- `clearProductForm` - будущая логика очистки формы.

### Экран "Покупки" `shopping_activity.xml`

- `openMainScreen` - возврат на главный экран.
- `openSettingsScreen` - переход на экран "Настройки".
- `scheduleDelivery` - будущая логика планирования доставки.
- `showFavorites` - будущая логика избранных товаров.

### Экран "Настройки" `settings_activity.xml`

- `openMainScreen` - возврат на главный экран.
- `openShoppingScreen` - переход на экран "Покупки".
- `saveSettings` - будущая логика сохранения настроек.
- `resetSettings` - будущая логика сброса настроек.

Все перечисленные методы добавлены в `MainActivity.java`, чтобы кнопки были привязаны и не вызывали ошибку при нажатии.

## Творческий компонент

Для целостности стиля добавлена собственная подложка иконко-кнопок `icon_button_background.xml`: светло-зеленый фон, зеленая обводка и скругление углов. Эта подложка используется на всех экранах для навигационных иконок.
