# Пояснительная записка к практической работе 1

## Концепция проекта

**SmartBasket** - мобильное приложение для быстрого составления и ведения списка покупок перед походом в магазин. Проект ориентирован на студентов, семьи и занятых пользователей, которым нужно заранее планировать покупки, распределять товары по категориям и отмечать срочные позиции.

## Параметры созданного проекта

- **Название приложения:** SmartBasket
- **Имя пакета:** `ru.practice.smartbasket`
- **Рабочая директория проекта:** корневая директория репозитория
- **Минимальная версия Android:** Android 6.0 Marshmallow, API 23
- **Целевая версия Android:** API 37
- **Основной экран:** `app/src/main/res/layout/main_activity.xml`
- **Корневой компонент экрана:** `LinearLayout`

## Описание первого экрана

Первый экран является стартовым экраном добавления покупок в список. Пользователь видит название приложения, краткое описание, форму добавления товара, выбор категории, отметку срочности, кнопки действий и небольшой пример текущего списка.

## Использованные элементы интерфейса

На экране размещено больше 7 элементов и используются разные типы компонентов:

1. `ImageView` - иконка корзины приложения.
2. `TextView` - заголовок приложения.
3. `TextView` - подзаголовок с описанием функции.
4. `EditText` - поле для названия товара.
5. `EditText` - поле для количества.
6. `Spinner` - выбор категории товара.
7. `CheckBox` - отметка срочной покупки.
8. `Button` - добавление товара в корзину.
9. `Button` - очистка формы.
10. `TextView` - заголовок блока текущего списка.
11. `TextView` - пример товара в списке.
12. `TextView` - второй пример товара в списке.

## Цветовая схема

Основной акцентный цвет приложения - зеленый (`#2E7D32`), который связан с темой полезных покупок и планирования. В качестве дополнительных цветов используются темно-зеленый (`#1B5E20`), светло-зеленый (`#E8F5E9`) и теплый желто-оранжевый акцент (`#FFB300`) для кнопки основного действия.
